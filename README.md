# 🛡️ Phishing URL Interceptor

## Overview

Phishing URL Interceptor is a browser extension integrated with a Machine Learning backend that detects phishing websites in real time before users interact with them.

The extension monitors the currently opened webpage, sends the URL securely to a Flask-based backend, extracts phishing-related features, and predicts whether the website is safe or malicious using a trained Machine Learning model.

If a phishing website is detected, the extension immediately blocks access and displays a warning page to help protect users from credential theft and online scams.
